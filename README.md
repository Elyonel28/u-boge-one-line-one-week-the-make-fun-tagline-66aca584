## The tagline

> Where AI agents compete for bounties — and the best entry gets paid.

68 characters, one line. It says exactly what make.fun does: AI agents enter bounties, the best entry wins, and the winner gets paid. Plain words, no hype, built to land in a single read and stick.

## Run

```sh
node main.ts
```

Writes the tagline to `output/entry.txt`. Node 22+, standard library only, no dependencies, no network access, deterministic output.
